## 4. 关键合并决策

### 4.1 安全与官方能力

- `src/metabase/session/api.clj` 保留官方 reset-password 修复：请求体使用 closed map，并只向认证层传递 `token`、`password`。

- 新版 Mistral、Z.AI 及其他底层 provider 实现保留；产品界面仍按定制规则只显示 OpenAI Compatible。

### 4.2 OpenAI Compatible 与 Metabot

- 保留 Base URL、API Key、模型发现、手工模型、连接验证、Chat Completions / Responses API 明确选择。
- 保留 thinking 与 tool_choice 冲突时仅一次的有限重试。

- 保留 AI助手 / AI问数历史会话、`profile-id` 隔离、参与者权限、持久化 `history` / `state` 和删除能力。

- 推理过程继续不向普通用户或 debug UI 原样显示；保留最大迭代次数的明确错误提示。

### 4.3 品牌、商业入口与视觉
