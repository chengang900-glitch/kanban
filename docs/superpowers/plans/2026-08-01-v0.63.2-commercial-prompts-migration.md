# Metabase v0.63.2 Commercial Prompts Migration Implementation Plan

> **2026-08-03 最终扩展：** 本计划的隐藏范围扩展到所有钻石图标、免费试用、升级专业版、Metabase Pro/Cloud、购买/查看套餐、专家支持、存储购买和软件版本更新推广，并覆盖 Transform/Python、AI provider、缓存、上传、邮箱、身份验证、常规设置及绕过共享 Upsell 的页面。完整范围见 `2026-08-03-v0.63.2-final-ui-branding-cleanup.md`。

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove confirmed trial, upgrade, and Powered by Metabase prompts from Metabase v0.63.2 while preserving calling interfaces and surrounding layouts.

**Architecture:** Keep exported component names and prop types stable, but make the commercial presentation components render `null`. This prevents upgrade flows, network checks, tracking calls, and branding nodes from mounting without forcing changes across their many callers.

**Tech Stack:** React, TypeScript, Jest, Testing Library, Bun.

## Global Constraints

- Work on `customization/v0.63.2-migration` based on official `v0.63.2`.
- Preserve all component exports and public prop types used by callers.
- Remove only commercial upgrade, trial, and Metabase-branding prompts.
- Do not remove security, legal, operational, or data-connection warnings.
- Keep embed containers and page layouts intact; only the prompt nodes become empty.
- Handle general admin documentation links in a separate migration batch.
