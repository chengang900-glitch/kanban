# Metabase v0.63.2 最终界面品牌与商业清理重施计划

> 本文件记录 2026-08-03 最终确认的界面规则。与 2026-08-01、2026-08-02 计划冲突时，以本文件和根目录两份总控文档为准。

## 1. 成功标准

1. 中文用户界面中的产品名称统一为“数据看板”，其他语言统一为“Dashboard”。
2. 登录标题只显示“登录”。代码变量、API、数据库字段、源码文件名、版权/许可证、商标和开发文档中的 `Metabase` 不修改。
3. 所有用户页面不显示钻石图标、免费试用、升级专业版、Metabase Pro/Cloud、套餐购买、专家支持或软件版本更新推广。
4. 管理员、主程序、数据工作室和 AI 配置页面只保留已确认的可用入口。
5. 默认语言为 `Chinese (China)`；个人资料隐藏社区翻译提示并按“姓、名”顺序显示。
6. 仪表板隐藏“洞察”，中文 Share/份额显示为“分享”，Treemap 显示为“矩形树图”。

## 2. 品牌和国际化

### 最终规则

- 中文 locale：`数据看板`。
- 非中文 locale：`Dashboard`。
- 法律商标句 `Metabase is a Trademark of Metabase, Inc` 保留原文。
- 登录页标题“登录 Metabase”改为“登录”。

### 主要实现位置

- `bin/build/src/i18n/create_artifacts/frontend.clj`
- `bin/build/src/i18n/create_artifacts/backend.clj`
- `src/metabase/util/i18n.clj`
- `src/metabase/server/routes/index.clj`
- `frontend/src/metabase/utils/branding.ts`
- `frontend/src/metabase/auth/components/Login/Login.tsx`

### 重施检查

- 新版本重新定位前端、后端语言包构建入口和 HTML 页面标题入口。
- 验证中文、英文和至少一个其他非中文 locale。
- 扫描用户可见源码时排除测试、开发工具、许可证、商标和技术标识，禁止机械修改代码标识符。

## 3. 帮助、管理员和数据工作室菜单

### 用户帮助菜单

- 只保留“键盘快捷键”。
- 隐藏“获取帮助”“下载诊断信息”“关于产品”等项目。
- 管理工具帮助页隐藏获取帮助、报告问题、专家帮助和“出错的问题”。

### 管理员设置

- 隐藏远程同步、软件版本更新、自定义可视化、外观、许可证、Cloud 和 Google 身份验证。
- 更新、Cloud、许可证直达页面返回 Not Found，避免只隐藏导航但仍可直接访问。

### 数据工作室

- 隐藏内容库、Schema viewer、依赖关系图、依赖项诊断和设置远程同步。
- 判断依据是最终确认的受限/钻石功能清单，不依赖图标是否仍由上游组件渲染。

## 4. 商业推广统一隐藏

### 隐藏范围

- 钻石图标和 gated 标签。
- 免费试用、免费升级、升级专业版、Metabase Pro/Enterprise/Cloud。
- 购买、查看或了解套餐，迁移 Cloud，存储购买和专家支持。
- 软件版本更新菜单、更新通知和促销卡。
- Transform/Python、Embedding、AI managed provider、缓存、上传、邮箱、身份验证和常规设置中的推广。

### 保留范围

- 安全、法律、维护只读、开发模式和必要操作警告。
- 被隐藏功能的底层实现、API 和数据结构，除非另有明确删除要求。
- 周边布局和公开组件接口，避免升级时造成调用方连锁修改。

### 主要实现策略

- 共享 `UpsellWrapper`、`UpsellGem` 和购买入口统一空渲染。
- 绕过共享组件的页面在调用点或页面入口单独隐藏。
- gated 标签在进入可见 tab/menu 集合前过滤，避免只隐藏钻石但留下不可用菜单。

### 主要实现位置

- `frontend/src/metabase/common/components/upsells/components/UpsellWrapper.tsx`
- `frontend/src/metabase/common/components/upsells/components/UpsellGem.tsx`
- `frontend/src/metabase/common/components/AppBanner/AppBanner.tsx`
- `frontend/src/metabase/nav/components/NavbarPromoSlot/NavbarPromoSlot.tsx`
- `frontend/src/metabase/common/data-studio/components/PaneHeader/PaneHeader.tsx`
- `frontend/src/metabase/transforms/`
- `enterprise/frontend/src/metabase-enterprise/transforms/`
