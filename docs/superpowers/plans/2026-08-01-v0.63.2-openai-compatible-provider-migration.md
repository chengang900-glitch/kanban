# Metabase v0.63.2 OpenAI-Compatible Provider Migration Implementation Plan

> **2026-08-03 最终覆盖：** 管理员设置页和所有前台/弹窗配置页只显示 `OpenAI Compatible`。Anthropic、Azure、Bedrock、OpenAI、OpenRouter 和 managed Metabase provider 均不显示；底层实现保留。完整范围见 `2026-08-03-v0.63.2-final-ui-branding-cleanup.md`。

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Migrate the confirmed OpenAI-compatible provider and provider-visibility customization onto Metabase v0.63.2 without replacing newer upstream AI behavior.

**Architecture:** Add an OpenAI Chat Completions adapter beside the existing provider adapters, expose credentials and model validation through the existing Metabot settings API, and use one shared default hidden-provider list for both the admin page and modal. Only OpenAI Compatible is visible; hidden provider implementations remain available in code for upgrade safety and focused tests.

**Tech Stack:** Clojure, Malli, React, TypeScript, Formik, RTK Query, Jest.
