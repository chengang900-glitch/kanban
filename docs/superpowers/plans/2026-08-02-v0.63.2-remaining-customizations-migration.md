> **For Codex:** Execute each task in order, keep every change traceable to the task IDs below, and do not restore UI-07.

**Goal:** Complete the confirmed v0.63.2 customization baseline: BRAND-04, AI-05, AI-06, AI-07, UI-01 through UI-06, and the missing migration-inventory records; then rebuild and replace the local Docker test deployment.

**Architecture:** Preserve v0.63.2 component and API structure. Branding changes stay in Chinese locale entries and prompt construction. AI history uses the existing participation-scoped conversation APIs, extends conversation detail to return a resumable `history` and `state` snapshot, exposes typed RTK Query hooks, and restores the existing omnibot Redux conversation through the existing snapshot reducer. Dashboard styling is scoped by `DashCard` DOM attributes and main-app classes, while SmartScalar and Progress expose only the semantic data hooks required by that CSS.

**Tech Stack:** Clojure/Toucan2/Malli, TypeScript/React, Redux Toolkit/RTK Query, CSS Modules, Jest/React Testing Library, Docker/JDK 21.
