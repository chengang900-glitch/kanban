# Metabase v0.63.2 Admin Documentation Links Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove confirmed external “Learn more” documentation links from selected Metabase v0.63.2 administration pages while retaining their explanatory text, settings, warnings, and business behavior.

**Architecture:** Modify only the presentation layer of the selected settings descriptions. Replace linked translated fragments with plain translated text, remove imports and URL lookups that become unused, and preserve every surrounding control, mutation, warning, and layout component.

**Tech Stack:** React, TypeScript, Jest, Testing Library, Bun.

## Global Constraints

- Work on `customization/v0.63.2-migration` based on official `v0.63.2`.
- Remove only external documentation links labeled “Learn more” or “Learn More” in the files listed below.
- Preserve explanatory copy, security guidance, settings controls, API calls, and error handling.
- Do not remove legal links, operational warnings, store links required by the cloud migration flow, or permission help links outside this batch.
- Do not migrate unrelated differences from the previous customized source tree.
