# Metabase v0.63.2 Permissions Documentation Links Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove external Metabase documentation links from the v0.63.2 permissions experience while preserving the built-in permissions help, migration explanations, warnings, controls, and save behavior.

**Architecture:** Keep the permissions help sidebar and all permission-level descriptions intact. Remove only external link render paths and their now-unused URL selectors/hooks/imports; where a link shares a row with a required action, retain the action and adjust alignment without restructuring the component.

**Tech Stack:** React, TypeScript, Jest, Testing Library, Bun.

## Global Constraints

- Work on `customization/v0.63.2-migration` based on official `v0.63.2`.
- Preserve the `Permissions help` toolbar button, help sidebar, permission descriptions, accordions, warnings, modal copy, dismiss actions, and permission editing behavior.
- Remove only external documentation links from the six permissions components listed below.
- Do not change permission values, Redux actions, API calls, feature checks, colors, or unrelated layout.
- Do not migrate unrelated differences from the previous customized source tree.
