# v0.65.2 初始化、帮助链接与图表术语定制

本次基于本地 `customization/uhooai-v0.65.2` 的产品提交 `e134ef6e`，仅修改本地源码与安装包，不部署或推送远程。

## 定制范围

| 用户需求 | 最终行为 |
| --- | --- |
| setup 入门指南 | 整个指南页脚不渲染 |
| setup 姓名顺序 | 姓在前、名在后；自托管初始焦点移到姓，字段/API 含义保持原样 |
| setup 用途 | 第一项 self-service-analytics 固定选中，四项均禁用；旧调用不能改写 setup 状态为其他用途 |
| setup 匿名采集 | 说明、文档链接和扩展说明移除，开关关闭并禁用；前端状态/提交为 false；新安装后端默认值与 setup 初始化均为 false |
| setup 版本邮件 | 开关关闭并禁用；完成页不调用订阅函数 |
| 管理员地图 | 隐藏“了解更多”，保留 URL、地图配置和安全说明 |
| 嵌入管理 | 移除 Useful links 标题、Embedding methods 和 Documentation 两张卡 |
| 权限与其他帮助链接 | 权限帮助移除文档页脚；公共 ExternalLink 隐藏英文 Learn more（含大小写/句号/扩展标题）与简体中文对应文案；原 Link/Anchor 实现已补齐 |
| Question 中文术语 | 271 条对象语义译文改为“图表”，保留普通提问、故障、API 字段与 URI |

## 语义和兼容边界

- 修改 `locales/zh-CN.po` 的译文，不改英文 msgid、代码变量 Question/card、API 路径、权限标识或数据库字段。
- `你的问题出现问题` → `你的图表出现问题`；`此问题出现了问题。` → `此图表出现了问题。`；AI 的“提问”和“要解决此问题”“没问题”保留。
- 中文 PO 中共审查 279 条 question 相关条目及其余含“问题”的译文；271 条调整（含不带 question 的另存提示），9 条普通问句或 API 字面量保留；占位符顺序保持一致。
- 隐藏的是 UI 中标为“了解更多”的帮助入口；普通功能导航、法律信息、其他标题的链接、后端 API 与权限能力保留。原生 AI、Keycloak、趋势图/进度条样式继续沿用此前定制。
- 开关锁定范围是 setup。未迁移已有实例的匿名采集配置，也未改变已有管理员设置权限；部署环境的显式环境变量应与此策略一致。
- Learn more 原始字符串仍可保留在源码/翻译文件中，由公共组件在渲染时隐藏。SDK CLI 文本、源码 README 和无超链接的企业功能说明不属于本次 OSS 网页入口。
