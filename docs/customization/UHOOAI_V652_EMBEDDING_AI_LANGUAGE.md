# v0.65.2：嵌入提示与 AI 推荐问题语言修订

日期：2026-10-29。产品源码：`39088d6a4ac4db6e0855c4bbb6ab04262a67a7d5`。

本轮按用户要求调整两处行为，沿用此前 setup、品牌、图表、权限及 Keycloak 定制。只更新本地源码和交付包；不部署服务器、不修改生产数据。

## 1. 获取嵌入代码页

在嵌入已启用、使用条件尚待确认时，隐藏“同意使用条件以继续。”标题。

- 保留“同意并继续”按钮，由管理员主动操作。
- 许可信息图标放在按钮旁，悬浮说明内仍可查看使用条件链接。
- 没有自动接受条款；后端许可判断和设置更新负载保持原样。
- 未启用嵌入和已经同意等其他状态，继续沿用原生启用流程。

实现位置：`frontend/src/metabase/embedding/embedding-iframe-sdk-setup/components/AuthenticationCard/EnableGuestEmbedsSection.tsx`。

## 2. AI 重新生成提示词

推荐问题原先由英文模板和英文示例生成，模板没有要求输出语言。本轮在表和指标共同的生成入口追加站点语言要求，明确仅问题内容使用目标语言，JSON 字段和结构保持不变。

| 全局站点语言 | 生成要求 |
| --- | --- |
| 未配置或简体中文 | 简体中文 |
| 繁体中文 | 繁体中文 |
| 英文 | 英文 |
| 其他已配置语言 | 对应语言 |

推荐列表由全站共享并持久化，因此采用“管理员 → 设置 → 本地化”的全局站点语言，不随点击者个人界面语言变化。手动重新生成与后台自动生成都经过同一入口。

管理员 AI 列表原先硬编码的 `Prompt`、`Model or metric` 表头也改为可翻译文案，简体中文显示“提示词”“模型或指标”。

**升级不会批量翻译已经存储的英文推荐问题。** 设置所需站点语言后，在管理员 AI 页面点击“重新生成提示词”，由现有模型生成新列表。仍需配置可用的模型及适用的模型/指标内容；原生权限、额度、错误处理和生成结果替换行为不变。

实现位置：

- `src/metabase/metabot/example_question_generator.clj`
- `frontend/src/metabase/admin/ai/MetabotAdminSuggestedPrompts.tsx`
- `locales/zh-CN.po`

不涉及 Qwen 适配、AI 问数对话系统提示词、模型选择、温度、最大 token、工具或历史功能修改。

## 4. 后续使用与回归

1. 升级前按总说明备份应用库及现有完整部署配置，保持既有 SSO/密钥和其他服务。
2. 升级后先核对运行时版本、hash 与 JAR 校验值，再验证嵌入代码页和 AI 页面。
3. 确认全局站点语言，手动重新生成推荐问题，检查实际模型输出语言及可运行性。
4. 没有可用模型时保留生成错误或无内容提示，不填造推荐结果，不宣称真实模型已验收。
